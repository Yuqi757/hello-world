TUT

博图图文教程

Step-by-Step
7 套分步教程。管脚含义配合「指令管脚详解」查看。

① 两台 1200 用 PUT/GET 互读互写

  1. 加两台 CPU，IP 同网段（.10 / .20）。
  2. 网络视图 → 下拉切连接 → 拖绿线建 S7 连接，连接表记下 ID（W#16#0001）。
  3. 两台 CPU 属性 → 防护与安全 → 勾允许 PUT/GET。
  4. 建 DB1/DB2 并取消优化的块访问，编译。
  5. OB1 拖入 PUT：REQ=M0.0 上升沿；ID=W#16#0001；ADDR_1=P#DB2.DBX0.0 BYTE 10（对方区域）；SD_1=P#DB1.DBX0.0 BYTE 10（本地）。读对方用 GET，RD_1 填本地接收区。
  6. 双方下载，监控 DONE=1 成功；ERROR=1 读 STATUS。
⚠① ID 与连接表不一致；② 对方 DB 没取消优化；③ 只下载了一侧。单作业 PUT≤212 / GET≤222 字节。

② Modbus TCP：MB_SERVER + MB_CLIENT

  1. 从站：DB10=Array[0..9] of Word（非优化）；OB1 调 MB_SERVER，MB_HOLD_REG=DB10，每周期调用，502 端口即开。
  2. 主站：建 TCON_IP_v4"ConnM"：RemoteAddress=.20，RemotePort=502，ConnectionType=11。
  3. 调 MB_CLIENT：REQ=M0.1；DISCONNECT=0；MB_MODE=0读/1写；MB_DATA_ADDR=40001；MB_DATA_LEN=10（值的个数）；MB_DATA_PTR=DB1；CONNECT="ConnM"。
  4. 监控：DONE=1 完成；MB_RESP_ERR 显示对方异常码（02=地址越界等）。
⚠MB_DATA_LEN 是值的个数不是字节数；DB10[0] ↔ 组态软件 40001。

③ Modbus RTU：Comm_Load + Master 读仪表

  1. 设备视图插 CM1241(RS485)，属性→系统常量记硬件标识符（如 271）。
  2. 调 Modbus_Comm_Load：REQ=首次扫描；PORT=271；BAUD=9600；PARITY=0；RESP_TO=1000。
  3. 调 Modbus_Master：REQ=轮询脉冲；MB_ADDR=1；MODE=0读/1写；DATA_ADDR=0；DATA_LEN=10；DATA_PTR=DB1。
  4. Master 的 MB_DB(输出) 接 Comm_Load 的 MB_DB(输入)；A/B 接线加 120Ω。
⚠校验位与仪表一致（常见 8-E-1）；A/B 接反=完全无响应。

④ PROFINET 挂 ET200SP

  1. 选项→管理 GSD→安装 ET200SP GSDML。
  2. 网络视图拖入 IM155-6PN，绿线连控制器；设备视图插 IO 模块得 I/Q 地址。
  3. 在线→分配 PROFINET 设备名称，名称与组态完全一致→"分配名称"。
  4. 下载，BF 灯灭 RN 绿 = IO 建立，程序直接用 I/Q 地址。

⑤ OPC UA 服务器

  1. CPU 属性→OPC UA→服务器→勾激活服务器（学习可允许匿名）。
  2. 服务器接口中发布要开放的 DB 变量（不发布不可见）。
  3. 客户端连 opc.tcp://192.168.0.10:4840 浏览读写。

⑥ 模拟量换算：NORM_X + SCALE_X

  1. 硬件配置记下 AI 通道地址（如 IW64）；AO 通道（如 QW64）。
  2. 输入：NORM_X（MIN=0、VALUE=IW64、MAX=27648）→ SCALE_X（MIN=0.0、MAX=100.0）→ 工程量 Real。
  3. 4~20mA：NORM_X 的 MIN 改 5530，低于 5530 判线。
  4. 输出：工程量 → NORM_X(0~100) → SCALE_X(0~27648, RESULT=Int) → QW64。
  5. S7-300/400 用 FC105 / FC106。
⚠SCALE_X 的 RESULT 类型拖块时选定；工程量上下限按传感器铭牌。也可在「实用工具」里用换算器直接算。

⑦ V90 PN 定位：FB284 SINA_POS（报文 111）

  1. 硬件配置添加 V90 PN，报文选 Standard telegram 111 (EPOS)；记下两个硬件标识符：STW 子模块 → HWIDSTW，ZSW 子模块 → HWIDZSW。
  2. 驱动侧设好 EPOS 基准（p2643 等）与回零方式；下载驱动参数。
  3. OB1 调 FB284（每周期）：ModePos=1；EnableAxis=1；Position/Velocity；OverV/OverAcc/OverDec=100；ConfigEPos=16#0000_0003（=%X0+%X1=1，解除 OFF2/OFF3；用硬限位/原点开关再按位定义加 %X3/%X6）；HWIDSTW/HWIDZSW 填标识符。
  4. ExecuteMode 上升沿触发定位；监控：AxisEnabled、AxisRef（已回零）、AxisPosOk（到位）、ActPosition。
  5. 点动：ModePos=2，Positive/Negative + Jog1/Jog2；%X8=1 时 ModePos=2 支持设定值连续实时改写。故障：AxisError=1 读 ActFault，AckError 上升沿复位。
  6. CancelTraversing=1 取消任务；IntermediateStop=1 中间暂停；EPosZSW1/2 看状态字原始位。可在「实用工具」的位解释器里快速查看各位含义。
⚠① 报文必须 111；② HWIDSTW/HWIDZSW 填错会 Error+Status 报硬件错；③ 自己给 ConfigEPos 赋值时必须保证 %X0 和 %X1 都为 1；④ 未回零（AxisRef=0）绝对定位不执行。
